# Zephyr Aerosystems

A fictional aerospace manufacturer homepage built as a static HTML/CSS/JavaScript site.

## GitHub Pages / Vercel

This repository is deployment-ready. `index.html` is at the repository root, with `styles.css`, `script.js`, and all required artwork in `assets/`.

- **GitHub Pages:** enable Pages for the repository and deploy from the `main` branch/root.
- **Vercel:** import this repository as a static project. No build command is required; the output is the repository root.

## Notes

Zephyr Aerosystems is a fictional brand/concept. Product names, specifications, capabilities, and company details on this site are fictional.
